# 🛡️ DakotaAC (Dakota Anti-Cheat)

Welcome to **DakotaAC**, the ultimate server protection plugin! 

Keeping your Minecraft server safe from hackers and cheaters is a tough job. DakotaAC is a highly optimized, all-in-one Anti-Cheat solution designed to automatically detect and block malicious clients, unfair advantages, and server crashers without lagging your server.

---

## ✨ Why choose DakotaAC?

* ⚔️ **Advanced Combat Protection:** Instantly detects and blocks unfair advantages like KillAura, AimBot, Reach, AutoClicker, and Criticals.
* 🏃 **Strict Movement Checks:** Prevents Fly, Speed, NoFall, Jesus, HighJump, and Phase exploits to keep gameplay fair.
* 🌍 **World & Player Security:** Stops Nuker, Scaffold, FastBreak, ChestStealer, and unauthorized Inventory modifications.
* 🛡️ **Anti-Exploit & Server Crasher Protection:** Blocks malicious packets (like PingSpoof or Crashers) designed to lag or take down your server.
* 🤖 **Built-in Anti-Bot & Anti-VPN:** Keeps your server safe from bot attacks and ban-evaders.
* 🔔 **Smart Admin Notifications:** Alerts your staff in real-time when a player is suspected of cheating.

---

## 📥 How to Install

You don't need any coding skills to secure your server. Just follow these simple steps:

1. Go to the **[Releases](../../releases)** tab and download the latest **`DakotaAC.jar`** file.
2. Open your Minecraft server's `plugins` folder.
3. Drag and drop the downloaded `.jar` file into the folder.
4. Restart your server.
5. *Optional:* Open the `config.yml` and `lang.yml` files generated in the `plugins/DakotaAC` folder to customize punishments, strictness, and messages!

---

## ⚙️ Commands for Admins

* `/dakota` - Main plugin command.
* `/check <player>` - Check a specific player's violation status.
* `/report <player>` - Allow players to report suspected cheaters.
* `/status` - View the Anti-Cheat performance and active modules.
* `/reload` - Reload the configuration files safely.
